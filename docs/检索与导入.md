# 检索与导入

人工阅读从根目录 README 和 `markdown/` 开始。程序读取 `data/kb.json`；检索系统按内容范围选择 JSONL：

| 范围 | 文件 |
| --- | --- |
| 仅联动 | `jsonl/game_retrieval_chunks.jsonl` |
| 基础库与联动合并 | `jsonl/retrieval_combined.jsonl` |
| 仅基础库 | `jsonl/retrieval_chunks.jsonl` |

三者存在包含关系，选择一套导入。JSON 与 JSONL 是镜像，按系统能力选择一种。导入时保留 `record_id`、`layer`、`continuity`、`evidence_ids`、`source_urls` 等原字段。

## 分层与来源

默认筛选 `layer=canon`。需要分析时显式加入 `inference`，回答中标注解读并保留依据；`fanon` 按 `worldline_id` 单独选择，当前为空。

`official_only_eligible` 按全部证据来源是否官方计算；`direct_only_eligible` 按全部证据是否实际读取正文计算。社区游戏文本转录保留其证据取得状态。每次引用附记录 ID、原始 URL 和场景定位。

基础库按 `phase`、`continuity` 等字段选择剧情阶段与作品。联动按 `narrative_level`、`assertion_kind`、说话人和 `spoiler_rank` 保留梦境、回放、角色评价与进度。档案、晋升、模组和语音按 `material_type` 区分，详见[联动检索规则](明日方舟检索使用规则.md)。

`context_record_ids` 指向可补取的较早或同进度场景，补取时继续应用同样的剧透过滤；它是阅读导航。`game_scene_coverage` 是覆盖审计，记录角色出场及复核范围，单独保存。

`source_issue_ids` 指向来源差异；`required_context_record_ids` 指向回答时需要一并读取的记录。涉及赠礼时同时取 `AKL009`、`AKL016`，即使材料类型过滤只返回一条。

## 主数据导入与研究流程

主数据建议按 `entities → sources → evidence → facts/relations/timeline → inferences` 及相应游戏集合载入，再按需载入独立世界线的 `fanon`。问答索引用于查询导航。

`candidate_claims`、`scene_reviews`、`access_audit` 和研究队列用于待核验流程，与默认事实检索分开。候选内容核验完成后按编录规则更新数据与证据状态。

## 本地使用与复核

本地中文检索只需 Python 标准库，命令见根目录 README。向量索引或聊天平台由使用者按平台导入和配置。

运行 `python -B -X utf8 tools/validate.py` 检查资料完整性；维护者先 `npm ci`，再 `npm test` 执行全部十二项工具。默认检查不写报告；显式生成的本地报告位于被忽略的 `validation/`。

语音触发标签、条件、voice_metadata与delivery_metadata随片段导出；引用时可直接给出实际标签和资源键。game_material_coverage与game_scene_coverage均为审计集合，与事实片段分开。

跨语言问题一并读取localization_notes，按check_id到game_localization_checks补取三版定位。AKL091为JP/ja日服新增段；SC005的关联上下文与SC004采用同一补取机制。game_localization_checks与其他覆盖审计一样不作独立事实片段导入。

## v1.8讨论上下文

讨论导航保存于data/game_discussion_guides.json与jsonl/game_discussion_guides.jsonl，单独用于编排。事实导入仍选原有三套检索文件之一。context_game.py提供无需第三方依赖的上下文提取；导航、过滤与证据输出规则见明日方舟检索使用规则v1.8节。

## v1.9文本验收与原作更新

game_answer_reviews为12项回答样本与人工复核记录，按管理资料单独保存；它与讨论导航均排除事实导入。v1.9时基础123条、联动193条、合并316条，当前数量见下节。主维护方向为原作，后续按仓库方式同步导出、验证和校验清单，不默认制作ZIP。

## v1.10原作检索

当前基础180条、联动193条、合并373条。tools/search_base.py读取基础片段与original_question_index，支持--include-inference、--official-only、--direct-only、--continuity及--phase；--phase为前缀，例如mygo_ep03与ave_ep03。结果附引用原始URL、证据定位及读取状态。导航是独立管理表，排除事实导入。

原作检索v1.12支持1—13话的中文数字／阿拉伯数字及话／話／集归一，如第三集、第3话。来源S117/S118的original_url为实际读取的一手访谈配信页，access_note另存原发行方URL及访问差异；引用沿证据返回实际阅读地址。
