# Skill安装与更新

仓库根目录就是完整的`sakiko-knowledge-base` Skill。`SKILL.md`提供检索指引，`agents/openai.yaml`提供展示名称与说明，data/及tools/随同安装。现有docs/、markdown/和schema/继续承担规则、阅读与结构约束的用途。

## 仓库与安装副本

| 位置 | 用途 | 更新方式 |
| --- | --- | --- |
| Git仓库 | 内容维护、审阅、版本管理 | 在此修改主数据、同步导出和验证 |
| 已安装Skill目录 | 其他会话中的检索入口 | 从选定版本重新安装或刷新交付文件 |

分别读取两处`data/kb.json`的`metadata.version`即可比较版本。工具根据自身位置找data/；在仓库维护时调用仓库内工具，其他项目中的问答使用所选安装副本。仓库已提交或已推送的版本不会自动覆盖安装副本。

## 从GitHub安装

向支持skill-installer的环境发送：

```text
请使用 $skill-installer，从 Xxxhite/sakiko-knowledge-base 安装仓库根目录（path=.），名称为 sakiko-knowledge-base。
```

远端安装取得指定分支或提交中的内容。需要可复现版本时，在安装请求中明确分支或提交。安装成功后，在新会话中调用：

```text
$sakiko-knowledge-base 祥子第1话的家庭场景有哪些依据？请区分事实与声优解读。
```

## 从已审阅本地版本安装或刷新

先执行AGENTS.md中的完整验证。复制的内容以`SHA256SUMS.txt`清单加清单自身为准，保持相对路径；目标目录名为`sakiko-knowledge-base`，使用当前环境指定的Skill安装位置。

已有安装副本时，先比较版本及本地修改，再执行明确授权的刷新。只同步交付清单，工作目录、Git元数据、依赖和报告留在仓库。刷新后校验清单文件的哈希，并从其他目录调用以下入口验证实际数据位置：

- 原作检索：父亲投掷物品F097、深层世界画面F099。
- 解读检索：显式开启inference后读取I023，保留渡瀬的推测归属。
- 联动检索：语音条件、AKL009／AKL016赠礼必要上下文。

提交与推送按用户授权执行；安装副本可以保持在已选版本，待仓库审阅完成后再刷新。
