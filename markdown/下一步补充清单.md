# 接下来补什么

按对用户讨论和检索的价值排序：

1. **序章、教学关与主线覆盖审计**：补最初进入梦境的语境，检查每关行动前后，建立祥子出场、缺席和已整理场景清单。
2. **语音触发条件与音频**：本版已有10项语音内容；继续补完整语音、信赖/晋升解锁、待机/触摸/作战等触发语境，以及中日文本与发音定位。
3. **梦境与罗德岛关系时间线**：围绕爱丽丝、贝娜、红豆、博士，分别记录梦中相遇、现实初见、档案评价、实际帮助。
4. **原作定位与版本差异**：对照客户端或完整录像补时间码、画面证据；优先核对SC004人偶赠送者和匿名听众线索。
5. **真实对话检索评估**：收集用户常见问法，检查能否取到足够场景、说话人、前后转折；再评估生成回答的准确性。

当前可优先回答：她如何对待队友的愿望、怎样调查海铃的遭遇、为何留恋家庭梦、在罗德岛做什么、如何靠音乐安顿情绪、怎样看待博士与泰拉经历。
